# MADVID architecture

MADVID follows a pipeline design:

1. Source resolution
2. Analysis of project, website, or store listing
3. Product understanding
4. Storyboard generation
5. Voice-over or caption selection
6. Video render
7. Validation and output placement

The library separates concerns into different modules so additional source adapters, styles, or providers can be added without disturbing the rest of the pipeline.
