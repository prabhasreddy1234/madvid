# Installation

## Requirements

- Python 3.10+
- An AI terminal or shell that can run the `madvid` command

## Install from source

```bash
cd madvid
python3 -m pip install -e .
```

## Register as a skill

Copy the `skills/madvid` directory into the user's skill directory or use the install helper:

```bash
./scripts/install.sh
```

After reloading the terminal, invoke `/madvid`.
